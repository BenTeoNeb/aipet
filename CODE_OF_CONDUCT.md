# Code of conduct

aipet adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, welcome newcomers, and keep discussions about the work.
Harassment of any kind is not tolerated.

This project is about children. Never share a child's personal data (names, voices, transcripts,
photos) in issues, pull requests or discussions, not even your own children's.

To report unacceptable behaviour, contact the maintainer privately through GitHub (for example via
**Security → Report a vulnerability**, which only maintainers can read). Reports are handled
confidentially.
