# Security and privacy

aipet processes children's speech. If you find a security or privacy issue (for example a way to
reach the debug API or the parents' space from another machine, to extract a child's memory, or to
make the pet bypass its guardrails), please **do not open a public issue**.

Report it privately through GitHub: **Security → Report a vulnerability** on this repository. You
will get an answer as soon as possible, and credit if you wish once it is fixed.
